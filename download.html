Genome: Viral Evolution – التطور الجيني الاستراتيجي

عن اللعبة

في Genome: Viral Evolution، تتحكم في فيروس يسعى للبقاء والتطور. يلتصق الفيروس بالخلية السليمة، ويصيبها، ثم يبدأ في التكاثر داخلها. مع كل دورة تكاثر، تزداد الخبرة (XP)، وعند امتلاء شريط XP ترتفع مستويات الفيروس وتظهر طفرات جديدة تزيد من سرعة النسخ، طول الجينوم، أو قوة البروتينات. عندما يصل عدد الفيروسات داخل الخلية إلى الحد الأقصى، تنفجر الخلية وتنطلق فيروسات جديدة لتبحث عن خلايا أخرى.

Genome.cs – نظام XP والطفرات
public void IncreaseXP(int amount) { XP = Mathf.Min(XP + amount, maxXP); ApplyRandomMinorMutation(); if (XP >= maxXP) LevelUp(); }
private void LevelUp() { maxXP += 100; XP = 0; CardUiManger.Instance.ShowLevelUpCards(this, 3); }

🧬 كيف يعمل التطور الجيني؟

  • XP والخبرة: يكسب الفيروس XP عند إصابة الخلايا أو إكمال دورات تكاثر. عند الوصول إلى maxXP، يرتفع المستوى وتظهر 3 بطاقات طفرات.
  • أنواع الطفرات: زيادة سرعة النسخ، تحسين البروتينات، زيادة طول الجينوم.
  • عتبات طول الجينوم: VeryLow → Low → Medium → High → Extreme → Ultra → Max.

🎮 محاكاة تفاعلية: دورة حياة الفيروس

شاهد الفيروس وهو يصيب الخلية، يتكاثر داخلها، ثم تنفجر الخلية وتطلق فيروسات جديدة. تزداد XP مع كل تكاثر، وعند امتلاء الشريط تظهر طفرة عشوائية (سرعة، جينوم، صحة).
